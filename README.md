# Emmanuel Udeka — Full-Stack Developer

A responsive portfolio featuring Emmanuel Udeka’s full-stack, mobile, and fintech work. The site includes selected project case studies, a résumé download, direct contact details, and links to live products and source repositories.

## Built with

- Next.js App Router
- TypeScript
- Tailwind CSS 4 and custom CSS
- Static export for GitHub Pages

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000/portfolio/](http://localhost:3000/portfolio/).

## Build the deployment site

```bash
npm run build
```

The static site is exported to `out/`. The checked-in `docs/` directory is the GitHub Pages deployment artifact.
